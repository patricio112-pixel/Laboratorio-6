## Descripción del proyecto

Este repositorio contiene las actividades del Laboratorio 6 de Programación Web. El proyecto utiliza HTML y CSS para crear un sitio web con varias páginas y navegación entre ellas.

## Páginas del proyecto

- `index.html`: página de inicio.
- `pagina1.html`: página sobre tecnología.
- `pagina2.html`: página sobre ciencia.
- `pagina3.html`: página sobre deportes.
- `css/estilos.css`: estilos del sitio web.
